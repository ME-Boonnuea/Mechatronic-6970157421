# ผลการทดลอง

โฟลเดอร์นี้รวบรวมภาพและวิดีโอจากการทดสอบระบบตรวจจับวัตถุบนสายพานลำเลียง โดยภาพที่ลงท้ายด้วย `_yolo.jpg` คือภาพที่ผ่านการประมวลผลด้วย YOLO และมีกรอบหรือ Mask ของวัตถุแสดงทับบนภาพต้นฉบับ

## สรุปการทดลอง

| รายการ | ข้อมูล |
|---|---|
| ระบบประมวลผล | Raspberry Pi 5, OpenCV และ YOLO-seg |
| กล้อง | Intel RealSense D435i |
| ลักษณะการทดสอบ | วัตถุเคลื่อนที่บนสายพานและหยุดที่ตำแหน่งตรวจจับ |
| ผลลัพธ์ที่บันทึก | ภาพต้นฉบับ, ภาพหลังตรวจจับ, Screenshot จาก Web Stream และวิดีโอ |

## การอ่านผลลัพธ์

- ภาพต้นฉบับใช้ตรวจสอบว่ากล้องจับวัตถุได้ชัดเจนและอยู่ในบริเวณที่ต้องการหรือไม่
- ภาพ `_yolo.jpg` ใช้ตรวจสอบตำแหน่งกรอบ/Mask และประเภทวัตถุที่โมเดลตรวจพบ
- ค่า Confidence ที่ต่ำควรนำไปตรวจสอบร่วมกับภาพต้นฉบับก่อนนำไปใช้กับการสั่งงาน Dobot
- ผลจาก YOLO เป็นข้อมูลช่วยวิเคราะห์ ส่วนการอนุญาตให้หยิบยังต้องผ่านการตรวจสอบสถานะและเงื่อนไขความปลอดภัยใน `dobot.py`

## ข้อจำกัดของผลการทดลอง

หน้านี้เป็นการแสดงตัวอย่างจากไฟล์ที่บันทึกไว้ใน repository ยังไม่มีตารางสถิติความแม่นยำหรือค่าคลาดเคลื่อนเชิงตัวเลข หากต้องการประเมินโมเดลอย่างเป็นระบบ ควรเพิ่มข้อมูลต่อไปนี้ในการทดลองครั้งถัดไป:

- จำนวนวัตถุที่ทดสอบและจำนวนที่ตรวจจับถูกต้อง
- ค่า Precision, Recall และ F1-score
- เวลาเฉลี่ยต่อภาพและอัตราการประมวลผลต่อวินาที
- ค่าคลาดเคลื่อนของความสูง/ขนาดเมื่อเทียบกับการวัดจริง
- จำนวนรอบที่ Dobot หยิบสำเร็จและหยิบพลาด
